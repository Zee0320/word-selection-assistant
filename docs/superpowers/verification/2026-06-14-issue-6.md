## Known Issues (需要后续调查)

### Issue 1: 空白区域拖拽时工具栏出现
- **现象**: 在桌面或空白区域拖拽时，工具栏短暂出现后消失
- **可能原因**: `readSelectedTextWithFallback` 回退到剪贴板捕获时，可能捕获到了剪贴板中的旧内容
- **位置**: `src/main/selected-text-capture-strategy.js` 和 `src/main/text-capture.js` 中的 `captureSelectedTextFromClipboard`
- **建议调查方向**:
  1. 检查 `waitForClipboardChange` 超时后是否返回了错误的值
  2. 检查剪贴板清空时机是否正确
  3. 考虑在 `captureSelectedTextFromClipboard` 中增加额外的验证

### Issue 2: 选择空白字符时工具栏出现
- **现象**: 选择只包含空白字符（空格、Tab等）的文本时，工具栏出现
- **可能原因**: UI Automation 的 `IsNullOrWhiteSpace` 检查可能没有正确过滤某些空白字符，或者剪贴板捕获了旧内容
- **位置**: `src/main/selected-text-reader.js` 中的 `buildUIAutomationSelectionScript`
- **建议调查方向**: 检查 PowerShell 脚本中 `[string]::IsNullOrWhiteSpace` 的行为，以及剪贴板捕获逻辑
