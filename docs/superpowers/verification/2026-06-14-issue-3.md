## Known Limitations

1. **Wayland not supported** - The implementation only supports X11. Wayland sessions will show "unsupported-platform" status.

2. **UOS/Deepin only** - This implementation is specifically for UOS (UnionTech OS) on ARM64. Other Linux ARM64 distributions are not supported.

3. **Dependencies required** - The following tools must be installed:
   - `xdotool` - For window focus detection
   - `xclip` - For PRIMARY selection reading
   - `xinput` - For mouse gesture detection

4. **No UI Automation fallback** - Unlike Windows, there is no accessibility-based text extraction on Linux.

## Deployment Notes

The deb package will be built for `arm64` architecture only. Users on other architectures (x64, etc.) should use the Windows version.
