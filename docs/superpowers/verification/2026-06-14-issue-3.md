## Known Limitations

1. **Wayland not supported** - The implementation only supports X11. Wayland sessions will show `wayland-unsupported` status.

2. **UOS only (NOT Deepin)** - This implementation is specifically for UOS (UnionTech OS) on ARM64. Deepin is NOT supported.

3. **Explicit X11 session required** - The `XDG_SESSION_TYPE` environment variable must be exactly `x11`. Missing or empty values will show `x11-session-not-confirmed` status.

4. **Dependencies required** - The following tools must be installed:
   - `xinput` - For mouse gesture detection
   - `xdotool` - For window focus and keyboard simulation
   - `xclip` - For PRIMARY selection reading

5. **No UI Automation fallback** - Unlike Windows, there is no accessibility-based text extraction on Linux.

## Deployment Notes

The deb package will be built for `arm64` architecture only. Users on other architectures (x64, etc.) should use the Windows version.
